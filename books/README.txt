# 我的书架（books/）

把电子书（txt / epub）丢进这个目录，我工作=读书时就会优先读这些真书。

## 不用建子目录

书一律**平铺在根目录**，分类由后端一张映射表管：`books/categories.json`

    {"version": 1, "books": {"三体.epub": {"category": "精品小说", "tags": ["科幻"],
                                           "by": "auto"}}}

分类取值优先级：
1. **manual** —— 你在网页端 / 命令里手动选过，永远不被自动重分类覆盖
2. **dir**    —— 子目录名（兼容旧摆法：books/科幻/三体.txt → 精品小说 + 标签「科幻」）
3. **auto**   —— 关键词自动分类：书名（含 epub 自带的题材标签）×6、作者 ×6、
                 正文抽样每命中一词 ×1，累计 ≥6 才认
4. **未分类** —— 都没信号，落兜底类，随时手动归位

## 22 个分类

精品小说、历史、文学、艺术、人物传记、哲学、宗教、计算机、心理、社会文化、
个人成长、经济、理财、政治、军事、童书、教育、学习、科学技术、生活百科、
期刊杂志、医学健康（+ 未分类兜底）

词表在 `corpus.py` 的 `GENRES`——觉得哪本书分错了，往对应类里加个关键词就行。

## 怎么加书

- **网页端**（最省事）：「此刻的 TA」抽屉 → 书架 → 拖进去（可多选）→ 这批书会
  列出来让你逐本确认分类和细标签 → 完事。
- **命令行**：文件丢进根目录，然后 `/refresh`；`/books` 看书架、
  `/books set <书名片段> <分类> [标签]` 改分类、`/books reindex` 重跑自动分类、
  `/books cats` 看全部分类。

## 和 TA 的口味怎么联动

人格卡的阅读偏好是两级：一级分类（22 类之一）+ 细标签（科幻 / 散文 / 杂文…）。
TA 先挑自己偏好的门类，同类里再挑对口味的，都没命中才读未分类的。
内置书摘（reading.py）和用户书库共用同一套分类，所以不管读哪边的书，口味都一致。

注意：阅读**不会**反过来改人格偏好——那是「朋友是稳定的锚」，不能漂。
