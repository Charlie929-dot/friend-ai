# friend-ai

朋友型 AI · MVP：主动触发引擎（问候 + 话题 + 作息）。

## 架构

通道可插拔，业务逻辑与 IM 解耦：

```
main.py ─┬─ channels/cli.py      本地命令行（开发调试用）
         ├─ channels/wecom.py    企业微信自建应用（正式）
         └─ channels/telegram.py Telegram（备案等待期兜底）
                │
            core.Engine ── 状态机(AWAKE/SLEEPING) + 防打扰 + 对话引擎
                │
    scheduler.py（APScheduler：早午晚问候/随机闲聊/作息切换，带随机抖动）
                │
    db.py（SQLite：状态/消息记录/计数器）  llm.py（DeepSeek）  persona.py（人设）
```

## 快速开始

```bash
pip install -r requirements.txt
cp .env.example .env   # 填入 DEEPSEEK_API_KEY
cp profile.example.md profile.md  # 可选：预填你的个人信息，AI 会把这些当成"已知道的事"
python main.py         # CLI 模式本地聊天
python main.py telegram  # Telegram 兜底通道
python main.py server    # 企业微信通道（云服务器上跑）
```

## CLI 斜杠命令（所有通道通用）

| 命令 | 作用 |
|---|---|
| `/help` | 帮助 |
| `/status` | 当前状态：作息/关系阶段/今日计数/模型 |
| `/model [名字]` | 查看或切换模型（如 `deepseek-reasoner`） |
| `/familiar` | 进入熟悉阶段：停止冒泡，主动只由触发源发起 |
| `/new` | 回到初见阶段：恢复高频冒泡 |
| `/new-friend` | **抽一位新朋友**（P1 核心玩法）：随机人格 + 随机名字 + 随机怪癖，归档当前数据库，新朋友用人格自我介绍 |
| `/friends` | 列出所有归档的"老朋友" |
| `/friend <编号>` | 换回某个老朋友继续聊（当前的自动归档，不会丢） |
| `/note <内容>` | 记一条事实便签（如 `/note 叫我小徐`），长期记住，优先级高于 profile |
| `/notes` / `/forget <编号>` | 查看 / 删除事实便签 |
| `/memories` / `/delmem <编号>` | 查看 / 删除 AI **自动**记住的事（记忆系统） |
| `/profile` / `add` / `reuse` / `clear` | 当前朋友持有的你的信息清单（**按朋友隔离**：新朋友零了解开局，可逐条填、沿用旧清单或跳过） |
| `/alias <编号> <别名>` | 给归档的老朋友改别名（新归档自动带人格名） |
| `/refresh` | 热重载所有文件（.env/配置/人设/prompt/语料），不用重启，只回一句"刷新成功" |
| `/groupidle on\|off` | 群聊自主闲聊开关（默认开：群里冷场时 AI 们自己慢慢聊，你开口就回来） |

## 娱乐模式（MVP）

聊天里提到具体游戏名就开局，规则由 AI 阅读后陪玩（game.py）：
- **成语接龙**：说"玩成语接龙"开局——每轮 AI 先评判你接得对不对，再接上你的成语给出下一个
- **海龟汤**：说"玩海龟汤"开局——AI 当出题人，只回"是/不是/不重要"，猜出汤底揭晓
- 游戏中提到另一个游戏名 = 换游戏；说"不玩了/结束游戏" = 结束
- **游戏进行中暂停一切主动消息**（冒泡/早午晚问候/轻催），结束后自动恢复；作息入睡/醒来不受影响
- 状态存各自 friend.db，和朋友隔离；/status 会显示当前在玩什么

## 归档机制（V2）：一个好朋友一份文件

每位朋友有稳定身份 `friend_id`（存库内 kv，随库走），归档文件 = `friend-<friend_id>.db`：
- **切换不再产生重复快照**：/friend、/new-friend 归档时覆盖更新 TA 自己的那份文件，文件名不带时间戳
- **归档时间**记在库内 `archived_at`（/friends 显示"最后归档"），每次归档事件追加到根目录 `archive.log`
- **/alias 改名只写库内记录**，文件名不变；/friends 按"相识时间"（首次归档）排序，顺序稳定
- 旧的时间戳快照归档已于 2026-10-06 迁移合并（migrate_archives.py），重复快照备份在 `backups/20261006-pre-merge/`

## 信息清单隔离（重要）

信息清单（称呼/年级/作息等预填项）**每个朋友各自一份**，存各自的 friend.db。新朋友开局对你一无所知——不再是全局 profile.md 注入（那会导致新朋友第一次见面就"知道"你的作业，穿帮）。老朋友（功能上线前的）继续读全局 profile.md，行为不变。

**切换互斥（PATH_LOCK）**：所有依赖"当前朋友库"一致性的多步流程（回复生成、后台记忆提取、主动消息、群聊发言/散群）与切库操作（/friend、/new-friend）互斥——切换瞬间在途的后台任务会先把当前朋友的活干完，切换才放行，数据不会写错朋友的库。

## 记忆系统（P1）

TA 现在会自己记事了：

- **自动提取**：每轮对话后后台提取值得记的事，带**五维标签**——类别（画像/偏好/计划/事件/人际/情绪）、时间、地点、人物、主题（学业/技术/健康作息/饮食/娱乐/社交情感/出行/财务/其他）；提取成功终端打印 `[memory] 记住：(类别|主题) 内容 @时间 @地点 @人物`
- **质量红线**：不记元信息（"用户没主动告知…"）、不记 AI 自己说的话（评价/昵称/调侃不是用户事实）、不记不确定推测、一条只说一件事
- **追加式时间线（不去重不合并）**：同一话题的新进展/新细节/计划变更直接新记一条，按 (类别, 主题) 分组，/memories 里同组按时间排列成时间线，能看到认知的演变；仅跳过原文完全相同的重复
- **互动里程碑也记**：深入讨论过的话题、TA 帮你弄懂的东西、一起做过的事——共同经历是老朋友之间最该有的记忆
- **时间标签绝对化**：提取时注入当前日期，"今天下午"→`2026-10-06 下午`、`明天早上`→次日日期；定位不到具体日期的（最近/以后/改天）留空
- **双时间维度**：事发时间（time_label，话题里讲的事发生在什么时候）和存储时间（created_at，TA 什么时候记下的）都存；/memories 每条显示"记于MM-DD HH:MM"，召回注入时没时间标签的记忆带存储日期锚点
- **相关召回**：发消息时把相关旧记忆注入上下文，五维标签都参与匹配；query 里的相对时间词（今天/明天/下午…）会换算成日期去命中绝对时间标签；命中一条后同组的更新进展一起带出，AI 看到的永远是最新状态，且注入时带时间标签（"你今天下午不是说……"）
- **话题弹药**：主动闲聊时有一半概率翻一条旧记忆问后续
- 记忆存在各自 friend.db 里，切朋友 = 切记忆；旧库自动迁移新列
- 分层：事实便签（/note，你亲口确认，最高优先）> 自动记忆（AI 自己提取）> 聊天上下文
- 注意：每轮对话多一次后台 LLM 调用（提取用，低温小输出），DeepSeek 成本可忽略

## 朋友联动：拉群互相对话（P2，2026-10-06）

- **/group <编号...>**：把当前朋友和指定的归档老朋友（编号见 /friends）拉进一个群；**/endgroup** 散群
- 每位朋友用**自己的人设卡和自己的记忆**发言（临时把 db 指到TA的库），CLI/IM 里每条消息显示发言人自己的名字（`[2026-10-06 14:22 稳稳] …`）
- **防无限循环**：全员回应一轮 → 提及接力（话里点了谁的名谁插队，每人限一次）→ 概率串话；AI 发言总轮次硬顶 6 轮，之后安静等你
- 群聊期间主动冒泡/问候暂停（guard 拦截），散群自动恢复
- **散群即沉淀**：完整群聊记录写回每位朋友的库（kind='group'，不污染 1:1 上下文和回填），并各自提取一遍记忆——同一场群聊，每个人记住的侧重点可以不一样
- **会话持久化**：每轮对话后 transcript 落盘（group_session.json）——/refresh 会先自动散场沉淀再重载；进程没散群就退出，下次启动自动补写回并各自提取记忆
- **时间感与私聊同步**（2026-10-07）：用户发言按字数模拟"阅读"（首位回应者读完整时长，后面的人边听边看、接话有小间隔）；回复前按字数模拟"正在输入"（`[稳稳] 正在输入…`）；长文本会有人先嘟囔一句"慢慢看"
- **自主闲聊**（2026-10-07）：你沉默 3-8 分钟（随机）后，AI 们会自己有一搭没一搭地聊——发言间隔拉长到 20-60 秒（省 token），一轮最多 6 句；睡觉的成员不参与；你一开口立刻打断闲聊、话题回归你；**/groupidle on|off** 可开关
- 组团玩游戏留待下一迭代（游戏状态机已就绪）

### 固定语料库 corpus.py（2026-10-07）

- 所有不走 LLM 的固定回复统一收进 **corpus.py**：睡觉迷糊回复、插话让步语、长文阅读提示、冒泡固定句，改语料只动这一个文件，/refresh 即生效
- `pick()` 抽取时记住该类上一次抽的是哪条，**不连续重复**（人味儿 = 不重样）
- 冒泡约 35% 直接抽固定语料（`BUBBLE_FIXED_PROB`），不走 LLM 省 token

### 记忆系统 v2（2026-10-06）

- **历史回填 /memfill**：把旧聊天记录分批提取进记忆（每批 16 条一次 LLM 调用）；每批用消息当天的时间作参照，老朋友 10 月 3 号说的"今天下午"锚定到 10-03 而非回填当天；断点续跑（kv 记偏移），中断后再跑接着来
- **删除待确认**：提取器发现错误记忆（AI 自己说的话/用户明确否定/直接矛盾）可提议删除，只标记 pending_delete 不真删；/memories 底部"🗑 待你确认"区，/delmem 确认忘、/keepmem 保留；待删除记忆不参与召回
- **AI 自动维护 profile**：聊天中说出确定性事实（称呼/生日/城市/作息/在忙的事…）时，提取器同步填进 TA 的 /profile 清单（"字段：值"格式）；AI 写过的字段可更新，你手动加的字段不覆盖——以你为准
- **"改"= 追加**：按追加式时间线，计划变更/信息更新直接新记一条，旧条保留为历史，不改写
| `/guard [on\|off]` | 防打扰开关（**默认关**）。开启后才限制：每日上限/忙碌静默/连续未回复熔断 |
| `/persona` | 查看当前朋友的人格卡（名字/类型/作息/冒泡频率/怪癖） |

## 人格池（P1）

每位朋友都是"抽"出来的：**6 种人格骨架**（阳光话痨/夜猫子/高冷毒舌/温柔治愈/老干部/中二乐天）× 3 个候选名字 × 10 种怪癖。人格不只是说话风格，还是一整套行为参数：

- **作息跟随人格**：夜猫子 10 点起凌晨 2 点睡，老干部 6 点起 22 点睡（/new-friend 或 /friend 切换后自动重排调度）
- **冒泡频率跟随人格**：话痨 x1.5，高冷 x0.6
- **生活日边界跟随人格起床点**（夜猫子朋友凌晨 4 点没睡还算"今天"）
- 人格卡存在各自的 friend.db 里，切朋友 = 切人格，天然隔离；没抽过卡的老朋友沿用默认人格

## 信息优先级（重要）

聊天纠正只活在最近 10 轮上下文里，会被冲掉。持久信息三层：**事实便签（/note）> profile.md > 聊天上下文**。AI 被纠正重要信息（称呼、偏好）时，用 /note 记下来才不会忘。自动从聊天提取事实属于记忆系统（P1）。

## 像人一样回消息（阅读模拟 + 分段连发）

- **假装阅读**：你发消息后 TA 不会秒回，按文本长度"阅读"（约 0.12s/字）；你连着发，阅读时间累加，但最多等 20 秒；内容太长时 TA 会先冒一句"内容有点多，我慢慢看哈"
- **分段连发**：回复按换行拆成几条消息连发，间隔按上一条长短计算——像真人连着发几条
- **正在输入**：正文发出前按总字数"敲键盘"（约 0.12s/字，1.2~8s），CLI 显示"xx正在输入…"，Telegram 用原生 typing 状态；TYPING_ENABLED=off 可关
- **插话检测**：TA 打字/连发期间你又说话了——打字阶段被打断则本次回复作废、直接回应你；连发中途被打断则停发剩余段、补一句"你先说？"（persona.INTERRUPT_ACKS 可调）
- 参数都在 `.env` / `config.py` 可调（READING_* / SEND_* / TYPING_*）

## 时间观：生活日 + 会话级等待

**生活日**（宏观）：AI 的"一天"不按日历午夜切换，而是**睡一觉醒来才算新的一天**（与休眠系统联动）：
- 凌晨 1 点半还没睡 → prompt 里告诉 AI"这还是『今天』的深夜"，禁止说"昨天"、禁止道早安
- 到达起床时间（默认 8 点）→ 才进入新的一天

**会话级等待**（微观）：AI 能分辨"这段聊天结束没"：
- 普通消息 → 会话标记为"进行中"，启动等待计时（10-20 分钟随机）
- 你突然没声了 → 到点后 60% 概率轻催一下（"人咧？""去忙啦？"），40% 安静等着；每段沉默最多催一次
- **话题结束三保险**（结束了就不催）：① 你说结束信号（拜拜/晚安/去忙……）；② AI 自己的回复带结束信号（"晚安啦"）；③ 都没抓住时 LLM 异步判官——把最后几句发给模型问"这段聊天结束了吗"，是就关闭会话
- 参数：`NUDGE_IDLE_MIN/MAX_MINUTES`、`NUDGE_PROBABILITY`

**未读留言**：你不在的时候 TA 发的主动消息（冒泡/问候）会存进未读队列（各自 friend.db 隔离），**一回来就重放**——启动时、`/friend` 换人时、或开口说第一句话时都会自动弹出"你不在的时候 TA 发的 N 条留言"然后清空；`outbox.log` 仍是长期存档。

## 关系阶段与主动频率

- **初见（new）**：空闲 30-60 分钟没聊天就主动"冒泡"（短消息/颜文字/表情），独立额度 12 条/天，不占普通主动上限
- **熟悉（familiar）**：主动消息只由触发源发起（早午晚问候 + 随机闲聊），6 条/天
- **自动转熟悉**：profile 已填项 + 事实便签 ≥ 5（`AUTO_FAMILIAR_INFO_THRESHOLD`）时自动切换
- 防打扰默认关闭（`/guard on` 开启）；睡觉拦截属于作息系统，永远生效
- CLI 没盯屏幕时，主动消息会同时写入 `outbox.log` 防止丢失

## CLI 时间戳与热重载

- **启动选朋友**：CLI 启动时先显示当前朋友是谁，列出归档老朋友——回车继续和 TA 聊、输入编号换老朋友、输入 `n` 抽新朋友。选择在调度器启动前完成，作息按选中的朋友排。
- **消息时间戳**：CLI 里每条消息带 `[YYYY-MM-DD HH:MM 名字]` 时间戳（发言人显示朋友自己的名字：人格卡名 > 别名 > "老朋友"，你的消息标记为"你"），离开一会儿回来也能分清消息是啥时候发的、是谁说的。
- **/refresh 热重载**：改了 .env、config 参数、persona 人设文案、人格池、记忆/防打扰语料后，输入 /refresh 即可生效，不用重启进程打断聊天；定时任务（作息/午间/随机闲聊）会按新参数自动重排。群聊进行中 /refresh 会先自动散场沉淀（写回记录+提取记忆）再重载，群聊内容不会丢。
  - 重载范围：config、persona、persona_pool、llm、memory、guard + .env
  - 不在范围：core/db/scheduler/通道层（引擎实例已创建，结构性改动仍需重启）

## 常驻运行的说明

主动消息依赖进程内的调度器，**CLI 必须常驻**。Windows 计划任务"定时打开 CLI"没有意义（主动消息需要持续进程），正确姿势：
- 开发期：CLI 常驻 + `outbox.log` 兜底
- 过渡期：`python main.py telegram` 常驻，主动消息推手机
- 完全体：备案完成后部署云服务器 + 企业微信，7×24 在线

## 企业微信部署清单（备案完成后）

1. 云服务器装依赖，启动 `python main.py server`（systemd 保活）
2. 企业微信后台 → 自建应用 → 配置「企业可信 IP」= 云服务器公网 IP
3. 「接收消息」设置回调 URL = `https://你的域名/callback`，填 Token 和 EncodingAESKey 到 `.env`
4. Caddy/Nginx 反代 443 → 8000，完成域名校验
