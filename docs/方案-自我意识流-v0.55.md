# 自我意识流（完全自我意识）· 方案说明

> 归属：需求概要 v0.55 · D 模块「自我意识流（完全自我意识）」主线的详细设计说明。
> 来源：2026-10-10 与小葵聊天 6 条反馈（实测 #36）里的问题 2/3/5/6，经用户拍板定稿（纯需求/设计，未动代码）。

---

## 一、要解决什么

TA 现在"对自己没有完全的意识"：不知道自己正在工作、不知道攒了多少钱、说不清自己的心情、被问"今天做了啥"答不上来（只能现编"出门晒太阳看猫"）。

根因：`work` / `mood` / `selfmem` / 内心独白 四处状态**散着注入**，且：
- Money / Energy 从不进 prompt（钱只在 HUD 给"用户"看，没让 TA 自己知道）；
- 内心独白每次用完就扔、不持久，跨轮无连续性；
- "读了什么"只在忙/心流相位注入，下班相位只注"事都忙完了"没细节。

---

## 二、核心概念：完全自我意识

TA 脑子里应该有一条**持续更新、第一人称的自我叙事**——像活人一样，脑子里始终有一个"我"在过：

知道我起了床、知道我在干活、会**主动瞄一眼**自己攒了多少、知道自己这会儿什么心情、知道我刚才在想什么、知道我读了什么、知道我答应了谁什么。

下面"完整范例"用"**一个动态页面 + 事件触发打印**"的比喻来描述这条流——**网页 / php 只是比喻，不是真要这么做**。真正的落点是：一条存在 db 里的第一人称流，事件驱动追加，每轮注入"当前状态行 + 最近几条流"给模型读。

## 四、架构落地（不真做网页 / php）

1. **一条持续追加的第一人称流**：存 db（新表或 kv），事件驱动追加，每轮注入"当前状态行 + 最近几条流"。
2. **事件 → 第一人称行**（确定性为主，只有"我在想"调 LLM）：
   - 作息切换 → `# {HH:MM}，我起床了 / 我去睡了`
   - 工作单元结算 → `# 忙完第 X 件，攒了 Z 块，剩 W 精力`
   - 收到留言 → `# 小徐给我留言了，我看看`
   - 内心独白 → `# 我在想：{独白}`（**持久化**，不再用完就扔）
   - 回复 → `# 我说：{回复}`
3. **主动查看（MCP 增强）**：`self_status` 工具，TA 主动"瞄一眼自己钱包 / 心情 / 今天干了啥"。**注入为主、工具为辅**——底子必须常驻注入，否则它又会忘了看、回到"不知道 120 块"；工具给"主动查看"留口子。
4. **睡前复盘浓缩**：把这条流浓缩进 `self_*` 正式记忆（给 selfmem 加"轻量连续版"数据源）。
5. **收敛散件**：把 `work.prompt_hint()` / `mood.prompt_hint()` / `selfmem.state_hint()` / 内心独白 四处散注，收成这一条流。

## 五、相关改动（分块）

| 块 | 模块 | 说明 |
| --- | --- | --- |
| 自我意识流（本文） | D | 完全自我意识主线 |
| 语气主轨 | A | 每轮定一个主导状态、其它注入从属（治语言割裂） |
| 表情包池 | E | 按情绪分桶 + 映射 + 聊天前翻看库存 + 懒人只甩表情 + 防重样 |

**愿景远期（暂不排期）**：待办事项（想分享没机会的队列，聊天时再打印）、刷手机爬虫（下班主动获取新鲜信息 + 分享链接、信息搬 B 库）。

**顺带修**：今日素材书名多套一层书名号（《《匆匆》》）。
