> v0.40（2026-10-09）：**对话中的主动延续落地**（C 模块，S3 建议顺序 ④）。在人设 `COMMON_RULES` 加一条「对话要有来有回，别把天聊死」引导——回答完对方的话后若还有自然钩子（正在做的事 / 流露的情绪 / 刚提到的新情况）就顺着轻轻追问一句或延伸一句，让对方有话可接；并带分寸约束（一次最多顺一句、别连环追问、别查户口；对方道别 / 说去忙去睡就别硬续）。根治"一问一答即止、AI 把话说死对方接不上话"。测试 32 项全过。

> v0.39（2026-10-09）：**情绪状态解冻 + HUD「心情」维度落地 + 需求池账目拆清**。①**心情维度**（`mood.py`）：心情由它自己的生活推（工作状态 + 精力 + 时段），**不等于 phase、不等于打断成本**——phase 答"它在干嘛"、打断成本答"找它的代价"、心情答"它自己的感受"。映射：心流=投入 / 忙=专注 / 歇=放松 / 下班=轻松 / 还没开工=慵懒 / 精力低=疲惫 / 深夜忙完=平静；`context` 注入"此刻的心情"语态，HUD 顶部加心情徽章（绿/灰/黄）。红线照做：不围绕任何人转、不改稳定人格、只描述自己状态。②**需求池账目拆清**：把"打断成本机制 + HUD"这条复合需求拆成独立条目（打断成本✅ / HUD 三态徽章✅ / 心情维度✅ / 离线留言待做暂缓），顺带全文档体检——日记系统、网页端 Web UI 各自挂着的"剩余尾巴"也一并拆成独立条目，反愧疚条目的假尾巴清理掉。测试 30 项全过。

> v0.38（2026-10-09）：**打断成本机制 + HUD 落地**（S3 招牌，需求文档标"下一个"的那条）。①`cost.py`：`costIndex = R×(1+F)` → welcomed/tolerated/costly 三态；**R** 由 phase/flow 给的阻力（心流 1.0 > 忙 0.7 > 闲 0.3 > 收工 0），**F** 由精力推的疲劳（精力越低越累、代价越高）。②三态落到**回复语态**：`context` 在紧急窗口之外注入"此刻的相处"提示（welcomed 多聊两句 / tolerated 正常 / costly 短慢 + 只说自己的状态）。③**红线兜底改写**：`core` 命中 `COST_BLAME` 归因措辞不再只打日志，直接换成"只说自己的状态"的安全句（`corpus.COST_SAFE_LINES`）。④**HUD** 顶部 phase 旁加三态徽章（有空/还行/正忙，绿/黄/红），网页端看得见"现在找它合不合适"。紧急通道仍是安全阀：急事窗口内跳过打断成本。测试 29 项全过。

> v0.37（2026-10-09）：**修 /help 等命令输出在聊天区糊成一坨**。根因：输入框里手敲的斜杠命令输出走 `addSys()` 渲染成 `.msg.sys`，这条样式既没 `white-space:pre-wrap`（多行换行被折叠成空格）又是 `text-align:center`（破坏 HELP 文本的空格对齐）；而按钮触发的命令走 `<pre>` 面板所以正常。给 `.msg.sys` 补 `white-space:pre-wrap` + `text-align:left` + 等宽字体，命令输出（/help /status /memories…）在聊天区也能正确分行对齐。

> v0.36（2026-10-09）：**Web 反馈一轮修——时间戳区分 + 聊天界面美化 + profile/记忆留痕**。①**消息时间戳区分**（bug1）：今天只显 `HH:MM`，非今天带日期（昨天/月日/跨年带年份），且换天插一条居中**日期分隔条**（微信/Telegram 风格）。②**聊天界面气泡化**（建议1）：气泡带小尾巴、时间戳落在气泡下方、系统/日期提示居中，视觉向微信/Telegram 靠拢；**去弹窗**（建议2）：换朋友/抽新朋友不再 `confirm`，归档自动进行、随时可换回。③**`/memories time` 按时间平铺**（建议3）：新→旧、每条带事发时间标签+存储时间，原分类分组视图保留并加一行引导。④**profile/记忆留痕 + 有疑惑交流**（bug2+建议4，本轮重点）：AI 自动填 profile 时把"上下文证据"存 **B 库**（`long_memories` 存对话原文），**A 库记忆挂 `long_id` 链接**跳转证据；`/profile` 显示 `〔证据#N〕`、`/profile why <字段>` 看原文；**稳定字段**（作息/生日/城市/称呼等身份级）遇到冲突新说法**不再静默覆盖**，标 `pending` 待用户确认（`/profile pending/accept/reject`），并注入 prompt 让 AI 主动找用户核实——根治"小葵把用户作息误判成十一点睡"。测试 28 项全过。

> v0.34（2026-10-09）：**网页端开机自启与常驻**（G 模块，自用阶段最后一块拼图）。①`daemon.py` **常驻守护**：盯着 `main.py web`，退了隔 5 秒重拉——除非看到 `web.stop`（否则永远关不掉：kill 一次它起来一次）；整条链子 `pythonw.exe` + `CREATE_NO_WINDOW`，**不闪黑框**。②`autostart.py` **开机自启**：优先计划任务（能查状态/能禁能删/不用管理员），注册不了兜底「启动」文件夹；顺手放**桌面快捷方式**（双击进聊天页，不用手敲地址）。`python main.py autostart [on|off|status|start|stop]`，网页里 `/autostart` 也能查（start/stop 只在终端做——在网页里把自己停掉就再也起不来了）。⚠️ 两个坑：**别用 `schtasks.exe`**（某些终端里连 `/query` 都报 path not found，改走 PowerShell 的 ScheduledTasks cmdlet）；**别用 `os.kill(pid, 0)` 探活**（Windows 上它等于 `TerminateProcess`，是杀人不是探活，要用 `OpenProcess`）。**遗留**：断线重连提示、移动端适配。

## 一、产品定位与项目约定

| 维度 | 结论 |
| --- | --- |
| 目标用户 | 自己专属（单用户，深度个性化） |
| 载体形态 | **两阶段已定档**：自用阶段 **网页端 Web UI**（浏览器打开就聊，服务端常驻本机）；推广阶段 **鸿蒙 App**（服务端上云）。成本暂不考虑 |
| 模型/运行 | 云端 API（DeepSeek）；自用阶段服务端跑**本机**，推广阶段迁**云服务器** |
| **一视同仁** | **项目宗旨**：AI friend 是独立个体，不知道"用户/主人"这种特殊身份，平等对待所有其他人（包括你）。记忆、日记、称呼都不围绕你特殊化——TA 记的是对自己有趣/重要/相关的事，日记是 TA 自己的生活 |
| 工具观 | 工具不是外部 API，是 TA 自己的"身体组分"（记忆检索=大脑回忆、行为接口=作息意愿）。**两层分离**：拟人化只管体感外壳，function calling 的契约内核（何时调/调哪个/参数/返回结构/标记 token）必须清晰 |
| 用户称呼 | 称呼来自每个朋友自己的 profile（事实便签"叫我X" > profile 称呼 > config.USER_NAME 兜底），不同朋友可有个性称呼，代码不写死 |

### 2.1 模块划分

需求池不再按优先级排长龙，改按**能力域**分成 8 个模块（A–H）。模块是稳定的，阶段是推进节奏。

## 四、必要性判定：砍掉与降级

以下条目本轮**不进排期**，附理由（都是判断，可推翻）：

| 条目 | 判定 | 理由 |
| --- | --- | --- |
| **财富系统**（原 P2 独立条目） | **降级：并入工作系统** | 钱是纯叙事资源，而它**目前唯一用途就是"打断有代价"**——与打断成本高度重复。先不独立，Money 作为工作系统内部变量；等有真实消费出口（如它用钱给你买点什么）再说 |
| **时间计划系统**（原 P3） | **砍掉** | AI 日程 + 用户日程 + 日历 + 时间表太重，自用用不上；"记住你的事"已由 B 模块事件记忆承担 |
| **伴侣/助手分身**（原 P3） | **砍掉** | 分身 = 围着用户转的不同角色，与「一视同仁」宗旨**直接冲突** |
| **阅读修炼人格**（原 P3） | **砍掉** | 人格随阅读漂移会破坏"朋友是稳定的锚"——朋友的性格不该乱变；且效果极难验证 |
| **群聊·时间统一 get_time** | **砍掉** | 群聊已移除（v0.27）；私聊里各朋友各自生活日是**个性化视角**，不是 bug |
| **名字多面共存**（原 P3） | **砍掉**（10-09 拍板） | 单值名字够用；重构名字层（改成"关系相关"的多值结构）收益不值成本 |
| **对话双线（审查线）**（原 P2） | **砍掉**（10-09 拍板） | 每轮两次 LLM（双倍 token）换"回复不突兀"，收益不确定、不值。真出问题再说 |
| **每晚可靠窗口** | **砍掉**（10-09 拍板） | 用户原话："没在工作自然就可以找到"——不需要额外再开一个固定空闲窗口 |
| **合规红线（自用阶段）** | **⏸ 暂缓** | 自用单用户不触发《办法》。**触发条件：对外推广（鸿蒙 App 上云）前必须完成 H 模块全部条目** |
| **未成年人保护** | **N/A** | 自用单用户不适用。若将来开放给他人再启用 |
| 人格体系 v2 | **降级为可选** | 6 骨架 + 怪癖已够用；先调研有没有更好做法 |
| 防沉迷时长提示 | **降级为可选** | 挂 HUD，自用阶段优先级最低（随 H 模块一起暂缓） |
