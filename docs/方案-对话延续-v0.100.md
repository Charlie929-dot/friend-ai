## 0. 重构起因——原案没动根因

原案（10-17 白天拍板）修三个症状域（游戏过期 / 删拦截 / 汤规则），但它自己在 0.4 诊断出的根因公式——**「TA 的话语权来自定时器与骰子，从来不来自『我欠你一句话』」**——原样保留。10-17 晚用户重构，五条新认知：

1. **随机冒泡没必要**：random（20%/小时骰子）经常与上下文不符、显得机械。开口必须有理由：有东西分享、临期挂念、到点承诺。
2. **开口的形态 = 念头**：不是定时器到点直接发消息（那是闹钟），是**念头注入意识流**（“小徐明天晚上要做ppt汇报，不知道ta准备好没有”“突然想到白天刷到的一个段子，真的笑死我了”），TA 结合上下文用自己的口吻开口——**注入的是念头不是指令**，上下文不合适可以不冒出来；用户回不回是另一回事。游戏过程中想到个分享 = 闲聊，很常见。
3. **待办重新定位**：`todos` = **提醒便签**（短期、不一定有时间、不必全完成——现状本来就是这样，名字和心智对齐即可）；确定时间的事 = **日历/日程**（TA 的任务、用户的计划、节日生日——手机日历那种功能）。
4. **无时间点承诺 = 临时挂起**：完成后立刻回来继续对话（读书素材链兑现）；实际翻书/查资料走既有工具链（`tools.py` / `open_link` / `lookup_online`，v0.95–0.98 已有地基）。
5. **游戏不是模式**：就是规则提示词注入——现状 `game.py` 已经是（kv 记游戏名 + `prompt_injection()`，无线程无状态机），保持。

## 1. 拍板记录（2026-10-17 晚，P1–P9）

| # | 议题 | 拍板结果 |

| **P9** | 无时间点承诺 | **不建队列、不做到期触发**（维持 10-17 白天拍板）；兑现链 = 素材链 + 念头（P2/P5）：TA 真在读那本书 → 素材产出 → 冲动 → 开口贴原文 → “临时挂起”自然回来 |

## 2. 重构后的开口全景

| 通道 | 去留 | 理由 |
| --- | --- | --- |
| 早安 / 晚安 | 留 | 作息锚点（wake/sleep） |
| bubble | 留 | 初见期破冰，阶段自动消失 |
| 明确承诺到点 | 留（events 现有） | 答应过的事到点自己想起（对话式，非闹钟） |
| **临期日历念头** | 新（批 3） | 挂念 / 了解近况 / 提醒，多触点 + 聊过取消 |
| **分享冲动念头** | 新（批 2） | 素材产出即冲动 + 每日预算 |
| 回复中浮出 | 留（增强） | 念头注入聊天 prompt（`stream.prompt_hint` + 【我今天刷到的】已有）→ 回复 / 游戏闲聊时自然带出 |
| random / nudge / noon | **删（批 1）** | 无理由触发，机械 |
| 判官 / `session_open` / `nudged` / `next_nudge_at` | **连坐退役（批 1）** | 全部消费者只有 nudge（`core.py:222-225` / `:343` / `:433-446` / `:592`）；**意外红利：省掉每轮回复一次判官 LLM 调用** |

**念头双出口**（P2 落地形态）：念头注入意识流 → ①预算/护栏内**主动开口**（带最近对话上下文，结合上下文说什么、怎么说）；②念头**留存意识流**，下次开口（回复/锚点）还会浮出——guard 拦住或 LLM 不可用时不丢。

## 3. 分批

### 批 1 —— 减法日（~半天）

- **删三个 job**：`scheduler.py` random_chat（:47-53）/ nudge（:59）/ noon（:39-40）+ `reschedule_all` 里 noon/random 行；`core.py` 删 `check_nudge` / `_reset_nudge_timer`（:581-601）+ 调用点。
- **判官退役**：删 `_judge_session_end` / `_judge_locked`（:426-448）+ `session_open` 全部读写（:222-225 / :343）+ `nudged` / `next_nudge_at`；ENDING_SIGNALS 会话跟踪随删（词表是否留作他用动工时查）。
- **guard 删游戏拦**（`:69-72` 整段 + 模块头注释同步）。
- **soup 补猜方作业**（`game.py` soup.rules）：对方考你时每轮只问一个“是/否”问题、问完就停等回答、别连珠炮别自问自答、角色可互换谁出题谁答“是/不是”。
- **game kv 过期**（45 分钟）：空闲 = now − max(`started_at`, **消息表最后一条消息时间**)——零 schema、零存量兜底、TA 自己主动问过一句也算这局活着。过期清 kv **直接 `db.set_kv`，不经 `stop()`**（`stop()` 调 `current()`，套娃递归——审查已踩明的坑）。
- **config/tuning 清理**：删 `NUDGE_*`（3 个）、`NOON_HOUR`、random 相关（双头同步）；persona 删 noon/random/nudge 场景文案。
- **测试**：`test_game_mode` 的“游戏中拦截”断言**必改**（`test_engine.py:148-151`）；nudge/session 用例改删（`test_engine.py:196-213`）；六源弹药用例随 `_inject_random_topic` 退役改造。

### 批 2 —— 念头通路（~1 天）

- **分享冲动**：`life.take_shareable_item()`（素材）/ 刷到未分享（`sources`）产出时 → 念头注入意识流（stream）→ 每日分享预算内**主动开口**；预算尽只作念头，锚点/回复浮出。预算进 tuning（双头）。
- **todos 消费点迁移**：打勾机制（`proactive_todo_id`）从 random 场景挪到冲动开口；“提醒便签”定位不改结构。
- **锚点 prompt 带念头**：`build_proactive_messages` 注入 `stream.prompt_hint`（早/晚安开口时念头浮出）；`_inject_random_topic` 六源机制退役（源头并入冲动生成）。
- 情绪陪伴（“我难过 → TA 多聊、不一定安慰只是陪伴”的念头）**暂缓**（批 4 议）。

### 批 3 —— 日历（~1-1.5 天）

- **`events.py` 扩展**：①临期提醒节奏——设置时 LLM 定触点（默认池：前一周/三天/一天/几小时随机挑）+ 提醒日当天随机时间触发；②**聊过取消**——对话中记忆召回命中该日历项 → 取消近期未触提醒（判定口径批 3 设计时定）；③**准备状态**字段随对话更新；④**年重复**——节日（公历内置一行数据）+ 生日（profile 稳定字段自动生成年事件）；农历不做（中秋手工建）。
- 抽取管道扩展：现在只收“TA 对朋友的承诺”，扩到 TA 自己的任务、用户说的计划。
- 明确时刻承诺（P6）现有 care 到点触发**原样保留**。

### 批 4（暂缓/待议）—— 情绪陪伴事件

“用户难过 → TA 多聊点（不一定安慰、只是陪伴）”的念头与冷却。临期日历的“了解近况”已盖一部分，是否单列机制看批 1–3 实测。
