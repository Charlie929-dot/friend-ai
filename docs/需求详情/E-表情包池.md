# 表情包池（情绪映射） · 需求详情

> 归属：需求概要 E 模块。主表一句话见 [需求概要-朋友型AI.md](../需求概要-朋友型AI.md)。

统一表情库存按情绪分桶（开心/吐槽/无奈/惊讶/委屈/得意/无聊/疲惫/害羞/生气…），文字 emoji/颜文字 + **表情图（img）**（v0.68 先落文字版、img 仅预留字段——**当时误整条打 ✅，v0.70 修正账目并把 img 做掉**）；情绪→表情**一一映射**；注入**前置到系统层**，AI 聊天前先"翻看"库存、允许"只甩一个表情"当懒人回应再补文字（呼应回复自主权"有权只回嗯"）；**防重样**（同一场对话不重样）。治"表情单一（😂 反复用）"（实测 #36）。**已落地**（v0.68）：内置桶/表情在 `corpus.EMOJI_POOL`（不可删）、用户新增的桶/表情存 `emoji_pool.json`（**全局共享**，换朋友不换表情库、不进 git）；新模块 `emoji_pool.py`（读 `buckets/items/payload` / 取用防重样 `pick/recent_seen` / 维护 `add_bucket/add_emoji/remove_emoji/remove_bucket` / 注入 `prompt_hint`）；注入**尊重人格** `voice.emoji`（几乎不用 emoji 的人格不注入、禁止的排除），**允许只甩一个表情当懒人回应**；网页端表情面板（输入框 🙂 按钮 → 分桶 tab + hover 情绪描述 + 点选即发 + 新增桶/新增表情/删自定义表情/删自定义桶）+ `/api/emoji` 接口。**表情图 img 已落地**（v0.70）：新增表情可选图片（魔数判型 png/jpg/gif/webp ≤2MB，存 `emoji_images/` 不进 git、md5 同图去重），`/api/emoji_img` 服务图片（防目录穿越），面板网格渲染图、聊天气泡整条是带图表情文字时渲染成图；删表情/删桶连带删图
