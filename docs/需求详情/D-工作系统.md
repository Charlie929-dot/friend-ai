# 工作系统 · 需求详情

> 归属：需求概要 D 模块。主表一句话见 [需求概要-朋友型AI.md](../需求概要-朋友型AI.md)。

**工作=读书**（用户拍板）：**优先读用户导入的真实电子书**（`library.py`，books/ 目录 txt/epub，分类走 `books/categories.json` 映射表的 22 类 + 细标签、段级进度持久化），没导入才回退内置书摘素材库 `reading.py`（公版经典，6 大阅读偏好分类）；每个工作单元读 **N 段**（默认 `WORK_READ_PER_UNIT=50`，约 1.1 万字/单元、读一本 15 万字约 2 周，可配）、按人格阅读偏好优先（爱读科幻先读科幻）、一轮读完循环；读完产出 1 条可分享素材（摘抄真实金句 + LLM 人格化读后感，`take_shareable()` 供 C 模块当内容源）。其余照旧：每单元消耗 E、产出 Money、满配额才"下班"、**单元前 20% 心流期**、时段按人格作息、惰性结算（关机重启接着算）。**醒来才排班**（[实测 #26](../实测反馈/#26.md)"进度条涨了人却在睡觉"）：没醒 plan 空、HUD 进度不涨；赖床晚起 = 可用时间变短 = **少做几件**（配额缩水），班不排进被窝。**工作内容注入 prompt**（[实测 #28](../实测反馈/#28.md)）：忙/心流相位 `prompt_hint` 追加"正在读《XX》"（`_current_reading()`），TA 答得上"你在忙啥"、不再瞎编"文献"
