# 休眠完整版 · 需求详情

> 归属：需求概要 D 模块。主表一句话见 [需求概要-朋友型AI.md](../需求概要-朋友型AI.md)。

**离线=工作专注**（用户拍板：工作单元进行中=离线不秒回，单元间隙/忙完=在线，可达性下降可预期而非随机）；**作息自主调节**（入睡/起床围绕人格锚点浮动：累/忙完→早睡、精力足没忙完→熬夜、睡得晚→赖床，`SLEEPY` 过渡态 + 惰性推算 + kv 幂等缓存）。**起床双语义修复**（实测 #26/#27）：`today_wake_at`（今天该几点起）与 `next_wake_at`（下次几点起）分开；起床缓存 `wake_days` 按日 dict（夜里反复问不抖动）；tick 赖床到点醒 + 深夜保护（凌晨 SLEEPY 睡回去不叫醒）+ SLEEPING 睡过头兜底（错过 cron 也醒）
