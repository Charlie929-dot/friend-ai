# 修炼人格（偏好养成） · 需求详情

> 归属：需求概要 A 模块。主表一句话见 [需求概要-朋友型AI.md](../需求概要-朋友型AI.md)。

偏好不再写死、从真实经历里**养成**（2026-10-11 用户拍板，是原「阅读修炼人格」的升级复活）。**三层**：内核（好恶强度/立场/雷区/语言指纹）**钉死不漂移**（防重蹈"朋友是稳定的锚"覆辙）；物理生活偏好（听歌/小店/房间等）降为**被动底色**（被问才答、不当主动话题）；兴趣偏好从**读/聊/刷**三源动态**强化/养成**。**机制**（用户拍板）：主动消息话题源=三源；意识流里 TA 表达了"感兴趣"的想法 → **即时规则记兴趣线索**（不调 LLM）；同一兴趣对象在流里出现 N 次 → **自动转正**成新偏好（不调 LLM）。**已落地**（v0.67）：新增 `interests.py`——阅读源 `work._settle` 读 genre 直接 +1、聊天源独白/回复「信号词+主题词」共现记线索（`corpus.INTEREST_SIGNALS/INTEREST_TOPICS`）、同一主题累计 ≥3 自动转正；转正偏好进 `kernel_prompt`「最近喜欢上的」块 + `context._inject_random_topic` 主动话题弹药；刷手机源占位。开关 `INTEREST_PROMOTE_ENABLED`
