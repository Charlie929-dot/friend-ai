# 自我意识流（完全自我意识） · 需求详情

> 归属：需求概要 D 模块。主表一句话见 [需求概要-朋友型AI.md](../需求概要-朋友型AI.md)。

一条持续追加的**第一人称自我叙事**，事件驱动（作息切换 / 工作单元结算 / 收到留言 / 内心独白 / 回复），每轮注入"当前状态行 + 最近几条流"。内容 = TA 对自己**完全的意识**：在干嘛（相位）、攒了多少（Money——现在只 HUD 给你看、TA 自己不知道）、心情（mood）、读了什么（reading 进度，下班相位也注入）、我在想什么（**独白持久化**，不再用完就扔）。把散落的 work / mood / selfmem / 独白四处注入**收敛成一条流**；睡前复盘把这条流**浓缩进 `self_*`**（给 selfmem 加"轻量连续版"数据源）。治 #2（不知道 120 块）/ #3（工作没记忆）/ #5（自我连续性）/ #6（语气割裂）。**📄 完整设计 + 全天范例见 [方案-自我意识流-v0.55.md](../方案-自我意识流-v0.55.md)**。**已落地**：第一步（核心闭环，v0.57）= 意识流表 `consciousness_stream` + `stream.py` + 五处事件钩子（作息/工作结算/离线留言/独白持久化/回复）+ 每轮注入含 money/energy；第二步（睡前浓缩，v0.58）= 睡前复盘把当天流浓缩进 self_*。**v0.80（[实测 #45](../实测反馈/#45.md) 三次暴露）**：①**对话上下文整段全量读**——`db.session_context()` 从最后一次 `wake` 切会话（还没睡=同一段会话），起床前的隔夜/早起留言全截掉，上限 `CONTEXT_MAX_MESSAGES=1000` 只防刷 token；独白层同改全量。废弃 `CONTEXT_TURNS`/`PROACTIVE_CONTEXT_TURNS`（保留配置兼容）。②**意识流统一时间轴全量全文注入**——不再"最近 4 条 + 截 60 字"；「此刻的我」就是轴的最后一行（缓存稳定前缀的尾巴）。③**事件补全**：开工/读到哪/读完/歇会儿/午休/**收工**（新增，治"下班了还说在读"）——`work.note_phase` 用 `stream_last_phase` 去重（同相位不刷屏）。④**待办队列 `todos.py`**（圆用户原设计）：读书素材 + 独白【我自己的话题】两个来源入队；每轮把"还没说的"注入当话题，**说过的打勾 ✅ 不再当新话题**——直接治"颠来倒去就一句"。⑤**反谄媚异议改条件触发**——删 `disagreement_rate`（不再掷骰子凑配额），真碰内核好恶/立场/雷区才表达不认同；补通用雷区（被敷衍/被说教/被要求表演热情/被替它总结）；第 5 条去冷感；独白【真实看法】改"哪个是真的写哪个"。⑥**模型换 DeepSeek-V4.1-Flash**（`deepseek-flash`），`effort` 默认 low（只在 V4 传）；**网页端账户菜单「模型设置」**可自助调 model/effort/temperature（写 `.env` 热生效，`/model` 命令统一全局）。测试 58 项全过（新增 `test_session_context` + `test_todos`；`db.add_stream` 修 ts 用事件时间而非写库当下）
