# 网页端 Web UI · 需求详情

> 归属：需求概要 G 模块。主表一句话见 [需求概要-朋友型AI.md](../需求概要-朋友型AI.md)。

**自用阶段主载体**：`python main.py web` → http://127.0.0.1:8787，浏览器打开就能聊（不用装 App），服务端常驻本机。**与 CLI 同一份 db**，网页只是另一块屏幕。已落地：HUD 常驻顶部（数据来自 `work.status()`）、消息增量轮询、**操作 UI 化**（换朋友/抽新朋友/改名/常用命令按钮，输出进侧栏面板）、`/restart` 一键重启、紧急勾选、**发送双发修复**（[实测 #25](../实测反馈/#25.md)：`/api/send` 返回消息 id，前端回显后推进轮询游标，不再双重渲染）、**素材数修复**（[实测 #28](../实测反馈/#28.md)：`materials` 是顶层字段，前端误读成 `work.materials` 永远 0）。**UI 重做 + 精化**（v0.59 三栏+三皮肤+意识流面板；v0.60 记忆卡+收起洞察栏+朋友列表精化）。CLI 保留作调试通道
