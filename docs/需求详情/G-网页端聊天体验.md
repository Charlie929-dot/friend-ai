# 网页端聊天体验（定位/目录/复制/表情面板） · 需求详情

> 归属：需求概要 G 模块。主表一句话见 [需求概要-朋友型AI.md](../需求概要-朋友型AI.md)。

网页端日常使用的体感优化（v0.69/v0.70）：**进入定位到最后一条**（`/api/messages?latest=1` 最近 N 条正序 + 总数，`before=` 翻更早历史），**新消息提示只在翻旧时弹**（初始加载不误报）；**左侧 minimap 目录**（细线收起=每消息一条、长短分日期/消息、当前阅读位置高亮线随滚动走；hover 展开文字目录、tooltip 完整消息、点击跳转**常亮高亮**到点任意处才消）；**意识流/调试面板一键复制**；**表情面板**（hover 图标自动展开+点击开关、切桶不退出、打开后不因移开鼠标就关、分桶标签**中间不动/边缘缓慢滑**、新增表情可带图）；v0.71 补：账号管理页治愈风、表情面板从按钮**膨胀**展开（治卡顿：打开不重复 fetch）、自己发消息自动回最底。v0.72–v0.75 补：**目录改右侧浮层**（细线常驻不被挤掉，hover 右侧浮出文字目录）、**细线滑动实时定位目录条目**（最近细线匹配，感应位置与细线 1:1）、**跳转高亮整行蒙色**（气泡透明融入、不单独露出来，每皮肤柔和显眼色 `--hl`）、**打断不显让步语**、**离线提示改灰色居中小字**、**正在回复提示**（覆盖 LLM 生成全程）、**登录页皮肤同步**。v0.109 补：**目录条目圆点按说话人分侧**——TA 的圆点在左、我的在右（颜色之外再给一层一眼可分的信号），手机目录窗口与桌面 hover 目录共用同一套样式。
