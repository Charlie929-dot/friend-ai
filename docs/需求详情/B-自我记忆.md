# 自我记忆（我说过的话） · 需求详情

> 归属：需求概要 B 模块。主表一句话见 [需求概要-朋友型AI.md](../需求概要-朋友型AI.md)。

`selfmem.py`：记"我自己的事"——立场 / 我答应过的事 / 我出过的糗 / 想聊没聊成的 / 对这个人的感觉 / 上次的内部状态；睡前一天一次 LLM 复盘写入（`diary.daily_review` 末尾）。**不参与艾宾浩斯遗忘**（"我说过的话"淡忘了 = 人格断裂）；每轮召回几条做**一致性检查**（这次别跟上次反着说）；内部状态跨天延续并每天向人格中位值拉回 20% 防漂移。命令 `/selfmem`、`/selfreview`
