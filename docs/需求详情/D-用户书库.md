# 用户书库（真实电子书导入） · 需求详情

> 归属：需求概要 D 模块。主表一句话见 [需求概要-朋友型AI.md](../需求概要-朋友型AI.md)。

把 txt/epub 丢进 `books/` 目录，TA 工作=读书时优先读真书（`library.py`）。txt 自动试编码（utf-8/gb18030）、epub 用标准库 zipfile 解包 + 剥 HTML（书名/作者/正文 + dc:subject），零新依赖、纯本地、合规（只读自己的书，不联网不传播）。`/books` 看书架 + 进度。**v0.77 分类改版（用户拍板：建目录太麻烦）**：书一律**平铺在根目录**，分类由后端映射表 `books/categories.json` 管（manual > 子目录名 > 关键词自动分类 > 未分类兜底）；22 个一级分类（精品小说/历史/文学/艺术/人物传记/哲学/宗教/计算机/心理/社会文化/个人成长/经济/理财/政治/军事/童书/教育/学习/科学技术/生活百科/期刊杂志/医学健康），每类配细标签；自动分类打分 = 书名×6（含 epub 自带题材）+ 作者×6 + 正文抽样每词×1，≥6 才认。**网页端书架面板**：批量上传（多选/拖拽）→ 这批书列出来逐本选分类和细标签 → 一键重新分类（手动指定过的不动）。**与性格/工作系统对齐**：人格 `reading_pref` 升级为两级（一级分类 + `reading_tags` 细标签），旧 6 标签自动迁移（散文→文学+[散文]、科幻→精品小说+[科幻]）；`reading.py` 内置书摘对外翻译成同一套分类，两边口味一致；选书序 = 一级分类命中 > 细标签命中 > 未分类 > 其他。**阅读不反改人格偏好**（人格漂移会破坏"朋友是稳定的锚"）。`/books` 子命令：`cats` / `set <书名片段> <分类> [标签]` / `reindex`。**v0.78**：书架改**独立居中弹窗**（原为右抽屉折叠项，太窄）+ 书名单行省略排版修复 + **epub 封面解析**（`cover_bytes()` 认 OPF 两种写法，`GET /api/books/cover?id=` 出图，书架缩略图 + `has_cover`）。**v0.79**：epub 元数据两个坑（OPF 命名空间拼错 → 按本地名解析；`dc:subject` 脏值 → `_clean_subjects()` 洗）+ 分类词表补 160 词（250 本实测「未分类」75→31）+ 已按 22 类各导入一本（计算机类这批书里没有，留空）
