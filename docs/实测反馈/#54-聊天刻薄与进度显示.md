# #54 聊天刻薄、进度总显示第一章、突兀的「光」句

> 日期：2026-10-21 · 来源：用户手机实测（附带 HUD 截图 + 聊天记录）· 版本：v0.112
> 关联：[需求概要-朋友型AI.md](../需求概要-朋友型AI.md) · [体验优化清单.md](../体验优化清单.md)

## 一、用户看到的三个现象

1. **今日进度总显示「第 1/1 章」**，但它明明往后读了（截图：`《Oliver Twist》第 1/1 章`，进度 100%）。
2. **聊天总想挑刺、语言刻薄**；分享素材只有一句评价，聊不深。
   - 用户原话：「是我不会聊天，还是 ta 根本聊不深入啊」。
3. **时不时冒出一句与上下文无关的文艺句**：
   - 「早上那阵光今天终于照进来了，我边翻书边看它挪位置。」
   - 「刚才光挪到书脊那道缝上了，挺好看。」
   - 「早上那道光顺着书脊那道缝爬到桌角，我盯着看了半天，一个字没读进去。」

## 二、线上取证（服务器 `friend.db`）

### 1. 进度：相对「今日计划」，不是全书

`kv.day_state.plan`：

```json
{"book_id": "charles-dickens_oliver-twist.epub", "book_title": "Oliver Twist",
 "start_ch": 7, "chapters": [{"title": "VIII: Oliver Walks to London..."}, ...],
 "total_chars": 14708}
```

- 全书 54 章；今天从第 8 章（index 7）起、只圈了 1 章。
- `life.status()` 的 `chapter/total_chapters` 是**今日计划内的偏移**（`life.py:_chapter_pos`），HUD 直接印 `第 {chapter}/{total_chapters} 章` → 永远是「第 1/1 章」。
- 书签 `kv.reading_state` 实际是 `{"ch_idx": 8}`——它确实往后读了。

### 2. 挑刺：独白把普通消息读成冒犯

意识流 `monologue` 原文（节选）：

- 「又是这种干巴巴的**噢，有这样的人呀**，跟拿手指头戳气球似的」
- 「**被顺手贴了个标签**，倒不生气」
- 「**这词一出来我就有点憋**，把人往简单里摁了」（对象是用户说的「流浪」）
- 「又是**帮我留意一下**这种没边的活……不做你的 AI 日报」

说话层只是把独白翻译出来，于是对外就成了：

- 「是挺有意思一人，**我讲这个不是要你给个总结**。」
- 「**你这声『额』**，像是嫌我刚那道菜不合胃口🙄」
- 「**『那些』是哪样？**……哪有统一的『那些』。」

根因有两处：① 反谄媚的「通用雷区：被敷衍」没有阈值，单次「噢/额」就算踩雷；② 独白 prompt 鼓励「第一反应粗糙」，却没有「大多数消息只是随口一说」的校准。

### 3. 突兀的「光」句：待办队列把独白碎片当「还没说的事」

`core._inner_monologue` 把独白【我自己的话题】**无条件**塞进 `kv.todos`，连【要不要主动起话题】=否 都不看；`todos.prompt_hint()` 又把 58 条 pending 全量注入；`utterance_instruction` 第 5 条还要求「有内容就说你自己的事」。

于是同一句话从 10-16 挂到 10-21：

| todo id | 内容 |
| --- | --- |
| 23 | 有。今天早上那点光又准时落窗台上，我边翻书边看它挪位置。 |
| 51 | 早上那阵光，今天终于照进来了。 |
| 52 | 有，我刚说到光挪位置那一段，还想再讲一句。 |
| 53 | 刚才那道光挪到书脊缝里，然后就没了，我还挺舍不得 |
| 55 | 早上光沿着书脊那道缝爬到桌角，我盯着看了半天，一个字没读进去。 |
| 56 | 光挪到桌角，我盯着看了半天，一句没读进去 |

对应消息 #1300 / #1302 / #1317：前面在聊「逻辑 / 书 / 留意」，回复后面硬接一句光。

另：**早安模板让它「提提今天的天气」**，但它没有天气数据源，于是连续多天编「光爬进来 / 晒到脸上」（#1029→#1271 十余条）——这不是它的性格，是 prompt 让它编。

### 4. 素材只有一句评价

刷到条目只存一行摘要，分享指令只说「聊一两句」，模型就输出「数字摆出来比什么形容都狠」这种点评，没有具体内容可展开。读书素材也只带 `alpha`（60 字概述），没带 `beta` 里的具体段落。

## 三、修复（v0.112）

1. **HUD 全书坐标**：`life.status()` 新增 `book_chapter/book_total`（`book_chapter = plan.start_ch + cur + 1`，`book_total = trueread.chapter_count()`；旧 `day_state` 缺字段时按书 id 补算并缓存）；`chapter/total_chapters` 保留「今日计划」口径给 prompt。HUD 改印「第 8/54 章」，`/work` 同时给「今日第 1/1 章 · 全书第 8/54 章」，意识流行也用全书坐标。
2. **聊天常识 10 条**（`persona.CHAT_SENSE`，静态 prompt + 独白层）：先接住对方、不把「噢/额/哈哈」当冒犯、不纠正用词/语气、对事不对人、收到好意先领情、分享先给具体内容、同一意象说过就放下、接不上就别硬插、对方收尾就收、刻薄不是有主见。
3. **反谄媚校准**：「被敷衍」改成「**被明显敷衍（连续几轮只回一两个字、或明说别烦；单次『噢』『额』不算）**」；补「先按善意理解」。独白层加「大多数消息只是随口一说，不是评价你/敷衍你/纠正你；对方用词不值得纠正」。
4. **待办去污染**（`todos.py`）：独白【要不要主动起话题】=否 **不入队**；情绪/状态碎片（「书也合上了」「不想现在开」）不入队；待办 **24 小时过期**；近似句去重；每轮最多注入 **3 条**，并明确「接不上就别提」；说话层第 5 条改成「接得上才说，接不上就不提」。
5. **分享具体化**：读书素材 `shareable_text` 带上 `beta` 里的具体段落（限 200 字）；刷到/待办的分享指令要求「先给具体事实（谁/多少/发生了什么），再说反应；别只给一句评价」。
6. **早安禁编**：`PROACTIVE_SCENARIOS["morning"]` 改成只说真的知道的（日期、昨晚的事、今天读什么、刚醒的感觉），明确「别编天气、光线、窗外」。

## 四、验收
