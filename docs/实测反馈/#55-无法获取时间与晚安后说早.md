# #55 报不出时间、晚安后一分钟「早！」

> 日期：2026-10-21 · 来源：用户手机实测（附带聊天截图）· 版本：v0.113
> 关联：[需求概要-朋友型AI.md](../需求概要-朋友型AI.md) · [体验优化清单.md](../体验优化清单.md) · [实测 #53](./#53-半夜不睡与回复消失.md)

## 一、用户看到的两个现象

1. **问「现在几点？」答「我真报不出精确的点，手边没表」**（23:45），还补了一句「凭感觉，光那片早该挪到桌角了」。
2. **23:24 刚说完「晚安」，23:25 就发「早！今天这个点醒，天已经亮了，窗子那边有光进来☀️」**，紧接着「昨晚那个……今天接着读《Oliver Twist》」。

截图时间线：`23:24 晚安` → `23:25 早！` → `23:45 现在几点？` → `23:45 手边没表`。

## 二、线上取证（服务器 `friend.db` + journal）

### 1. 晚安后 13 秒「起床」

`consciousness_stream`：

```
533  23:24:22  reply  我说：那小子的事我先不追了…晚安！
534  23:24:47  sleep  我困了，去睡了
535  23:25:00  wake   我伸了懒腰，起床了
536  23:25:06  reply  我说：早！今天这个点醒，天已经亮了…
```

- `kv.state` 当时是 `AWAKE`，`kv.sleep_started_at` **为空**——那次入睡跑在旧进程上。
- 服务器 `systemctl show friend-ai -p ActiveEnterTimestamp` = **23:25:58**：v0.111/v0.112 是 23:25:58 才重启加载的，**这次「秒醒」发生在修复上线前 58 秒**。
- 因此「秒醒」的代码根因已由 v0.111 的 `sleep_started_at` 修掉（见 [实测 #53](./#53-半夜不睡与回复消失.md)），本条补充的是**没有入睡记录时仍会诈尸**的兜底漏洞 + 早安文案不带时间闸门。

### 2. 独白层根本看不到钟点

23:45 那轮 `monologue` 原文：

```
【第一反应】问这干嘛，我又没有表。
【真实看法】普通问题，没想法——准确的钟点我看不到，只能凭光判断个大概，早上七八点的样子。
【我最想说的】我真报不出精确的点，就知道太阳已经爬过窗沿了，顶多算个早上七八点吧。
```

`core._inner_monologue` 的 system 只有 `monologue_prompt() + selfmem + 整段会话`，**没有当前时间**；第 2 层又必须按「铁律 1：不许改变立场」照独白翻译，于是对外就成了「手边没表」。`persona.dynamic_system_prompt` 里的【当前时间】只有第 2 层看得到，救不回来。

## 三、修法（v0.113）

1. **时间锚点抽公共函数**：`persona.clock_hint(now)`（日期+星期+钟点+时段，含熬夜的生活日说明；**日期/星期用真实墙钟**——过了午夜还拿生活日报日期会说出「10月21日 00:10」这种不存在的时刻），`dynamic_system_prompt` 复用它；`core._inner_monologue` 把 `clock_hint()` 拼进独白层 system——**时间是最基本的事实，定立场的那一层也得知道**。
2. **说话层补铁律**：`persona.utterance_instruction` 第 8 条——「你清楚现在是几点（见【当前时间】）；被问就照实说，别编『手边没表/看不到钟点』，别把深夜当早上」。
3. **早安只在该发的时候发**：`offline.tick` 的 SLEEPING 兜底再加一道闸——**已经过了今晚入睡点还在睡，就该睡整夜**，不许拿「今天早些时候该起了」叫醒（没入睡记录的老库也不会深夜诈尸）；`core._do_wake` 只在 `05:00–12:00` 发「早！」，深夜被兜底唤醒只记醒来、不说早安。
4. **早安场景以真实时间为准**：morning 场景保留「别编天气/光线」，并由上面的时间闸门兜底——不是早上就不许说「天亮了」。

## 四、测试与验收

- `test_persona_kernel`：`clock_hint` 含钟点/时段、`dynamic_system_prompt` 带 23:45、说话层铁律含「你清楚现在是几点」。
- `test_inner_monologue`：独白层 system 必须含「【当前时间】」。
- `test_just_slept_not_woken`：新增「连入睡记录都没有时，23:25 也不许被兜底叫醒；第二天早晨照常醒」。
- 全量 **95/95**。
- 线上验收：部署后问「现在几点」应直接报钟点；当晚 `晚安` 后不再 13 秒起床。

> 备注：23:25 那条「早！」及由它提取的「今天早上醒来天已经大亮」记忆仍在线上库里，属于历史事实（当时确实发了）；修复后靠【当前时间】校准，不再把深夜当早上。
