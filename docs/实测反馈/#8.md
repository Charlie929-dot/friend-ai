# 实测反馈记录 #8（2026-10-07，失忆自证循环）

**Bug：初遇朋友私聊"依然不记得群聊的事"——越问越失忆**

- 现象：修复 #7 后实测，用户问初遇朋友"你现在想起来群聊的事了嘛"，仍答"真没有"，且各朋友（小葵/阿燃）也跟着说"初遇失忆了"
- 根因（关键，不是召回问题）：**记忆被"失忆"这件事污染**。之前初遇朋友确实不记得（旧 bug），用户反复追问"记不记得"，提取器把对话过程当记忆记了下来——`小徐发现我不记得群聊内容，说我失忆了`、`小徐不愿相信我不记得、反复追问`、`初遇失忆了，连群聊的事和阿燃都不记得`……这些错误记忆字面含"群聊/失忆"，bigram 得分反而最高，私聊时排在真实群聊记忆前面，AI 一读就"我确实不记得" → 形成自证循环
- 修复（2026-10-07）：①**提取器防污染**——`_validate` 加 `_SELF_AMNESIA`（我不记得/我失忆/我想不起来/我忘了）与 `_MEMORY_QUIZ`（追问/是否还记得/记不记得）两道确定性正则丢弃，EXTRACT_PROMPT 质量红线加"不记失忆类"（含"某位朋友失忆了"这种别人视角描述）；②**清理数据**——备份后删掉全库 18 条污染记忆（初遇朋友 5、阿燃 7、小葵 1，含归档副本）。清理后实测召回即恢复正常（返回真实群聊记忆）
- 经验：记忆系统的正确性 = 提取层（记对）> 召回层（找得准）。召回算法再准，库里存了"我不记得"也会被召回到前面；向量检索解决不了"记错"的问题
