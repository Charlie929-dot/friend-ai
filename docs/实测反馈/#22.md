# 实测反馈记录 #22（2026-10-09，命令输出糊成一坨）

**现象**：在输入框里敲 `/help`（或 `/status`、`/memories` 等任何多行命令），输出在聊天区挤成一坨、换行全没了；但点侧栏按钮触发的同名命令，输出正常分行。

**根因**：两条渲染路径不一致。按钮触发 → `runCmd()` → `panelDone()` → 写进 `<pre id="pOut">`，`<pre>` 默认保留换行；输入框手敲 → `send()` → `addSys()` → 生成 `.msg.sys` 元素，而 `.msg.sys` 的 CSS 既没有 `white-space:pre-wrap`（浏览器把多行文本的 `\n` 折叠成空格），又是 `text-align:center`（HELP 里用来对齐的空格也失效）。

**修**：给 `.msg.sys` 补 `white-space:pre-wrap` + `text-align:left` + 等宽字体（`ui-monospace,Consolas,monospace`），并 `align-self` 由 center 改 flex-start，命令输出块靠左、保留换行与空格对齐。

**教训**：同一个数据（命令输出）走了两条渲染路径时，要保证两边的换行/对齐策略一致；给任何"会放多行文本"的容器默认想清楚 white-space。
