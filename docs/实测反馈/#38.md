# 实测反馈记录 #38（2026-10-11，闻屿两个 bug → 修 + 修炼人格方向对齐）

**背景**：小徐贴了闻屿（安静敏感型 quiet）的两条主动消息，指出两个问题：①随意编造生活场景（"循环副歌""热粥配咸菜""楼下那家店"），期望"ta 的生活就只有阅读工作、和朋友聊天、刷手机获取信息"；②本来该分成两段的话没分开（"刚从书里抬头…热粥"和"《左传》…盟誓"黏成一条）。

**根因**：
1. **编造生活场景**：不是 LLM 凭空乱编，是**人格卡喂出来的**——闻屿的 `kernel.likes` 里写死"把同一段旋律反复听十几遍""便宜但认真做的小店小馆子"等物理偏好（intensity≥4 会注进 system prompt），LLM 很"忠实"地照着编出"循环副歌""楼下那家店"。同类物理偏好散落在 7 张卡里（阳光话痨"拉人吃饭/运动出汗"、夜猫子"便利店热食"、治愈"养植物"等）。
2. **两段话没分开**：主动消息路径 `_proactive` 直接 `_send(reply)` 整段发出，没走 `_generate_reply` 的分段逻辑——LLM 按 COMMON_RULES 约定用换行分了两段，代码没拆。

**落地（阶段 A，本轮）**：
1. **likes 加 `passive` 标记**：`persona_pool` 七张卡共 19 条"物理动作/场景"类条目（听歌/做饭/逛店/运动/房间/植物/便利店等）标 `passive:true`，社交/思考/工作/时段类保留。
2. **`kernel_prompt` 渲染分块**：`_fmt_likes` 支持拆 active/passive；likes 渲染成两块——"【你真的喜欢】会主动提起"和"【你的底色偏好】被问到才简单答、别主动当话题"。full 层（独白）全依据照注、compact 层分块。
3. **「生活三源」约束**：`COMMON_RULES` 加一条（生活就三件事：读书/工作+聊天+刷手机看信息，没有身体，主动开口只从这三件取材、别编"循环副歌/热粥/楼下店"）；`PROACTIVE_SCENARIOS` 的 morning/noon/random 指向三源。
4. **`_proactive` 分段**：reply 按换行拆段逐条 `_send`，一次主动行为计数只加一次。

**测试**：58 项全过（新增 `test_likes_passive_split` + `test_proactive_segment`）。

**「修炼人格」方向（阶段 B，下一轮，用户拍板）**：
- 用户澄清：物理生活偏好**可以保留**，只是**不当主动消息话题源**、降为"被问才答"的被动预设；后续从**读/聊/刷**三源里**强化已有偏好、养成新偏好**——"相当于增强版的阅读修炼人格，但不只是阅读，就是修炼人格"。
- 内核层（好恶强度/立场/雷区/语言指纹）**钉死**，修炼只发生在"兴趣偏好"层（防重蹈"人格漂移破坏朋友是稳定的锚"）。
- 机制（用户拍板）：偏好存储=给 likes 加标记（本轮已做）；修炼触发=**即时规则记录**，且**意识流中表达了感兴趣的想法才记录**（不是机械"读什么类就+1"）；同一兴趣对象在流里出现 N 次→**自动转正**（不调 LLM）；「刷手机」这一维**先占位不做**（爬虫是远期愿景）。
