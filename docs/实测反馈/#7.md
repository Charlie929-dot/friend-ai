# 实测反馈记录 #7（2026-10-07，群聊记忆私聊可见性）

**问题：群聊记忆在私聊里"时记时不记"，只有"初遇"记得住**

- 现象：群聊记忆（source='group'）在私聊里只靠"最近 5 条无条件兜底注入" + 关键词硬命中两条腿，割裂——刚散群记得、记忆一多就丢，最后通常只有"初遇"（认识阿燃）这种被反复强化的记得住，其他群聊内容私聊里记不得
- 用户拍板：私聊要**完整记得**群聊的事，朋友是同一个"人"（不是群聊/私聊两个平行世界）
- 修复（2026-10-07）：①私聊召回统一纳入群聊记忆——最近 `_GROUP_RECENT_COUNT` 条群聊记忆加温和分 `GROUP_RECENT_BONUS`（默认 1.2，弱于群聊场景 2.0，且必须 ≥1.0 才能过 recall 的 `score>=1.0` 召回门槛），更早的靠关键词命中；②删掉 `recent_group_memories` 独立兜底（割裂根源）；③`_memory_message` 召回含群聊记忆时补一句"带「群聊」标记的是在群里发生的，别搞混"来源提示
