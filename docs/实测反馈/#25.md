# 实测反馈记录 #25（2026-10-10，网页端发送文字出现两次 + 引用对话建议）

**现象**：网页端聊天，发送一条文字会在聊天区出现两次（重复显示）。

**待查方向（未处理）**：`web/index.html` 的 `send()` 发完先 `addMsg({role:'user', ...})` 手动回显一条，紧接着 `poll()` 又从 `/api/messages?after=lastId` 把 db 里同一条拉出来再渲染一遍——疑似"手动回显 + 轮询渲染"双重渲染（`lastId` 没正确跳过刚发的那条）。待排查确认后修。

**建议（转需求池）**：希望做「引用对话」功能——像微信/QQ 那样点选/长按某条消息，回复时带上被引用的原文，让多轮对话里"回哪句"一目了然。

**处理**：本轮只记录、不实现（用户拍板"先同步到文档，不做处理"）。
