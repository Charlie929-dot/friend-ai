# 实测反馈记录 #29（2026-10-10，收尾三小事：登录页 TOTP 溢出 / 临时目录债 / AGENTS.md 对照表补齐）

**背景**：用户在体验服务器版时提了三件事——①把新增文件的说明补进 AGENTS.md ②问项目根一堆 `tmp*` 文件夹有没有必要、能否直接删 ③登录页动态验证码 UI 突出来了。

**现象①：登录页动态口令输入框溢出卡片（真前端 bug）**

- 现象：开了 TOTP 后登录页的"动态口令"输入框比密码框宽，撑出了卡片边界。
- 根因：登录页 CSS 把输入框样式限定为 **`.field input`**（`width:100%` / 边框 / 内边距都在这个选择器里），但 `auth.TOTP_FIELD` 里的 input **没有被 `.field` 容器包裹** → 它只吃到 `input[type=text]{letter-spacing/font-size/text-align}`，没有宽度约束，用浏览器默认宽度渲染 → 溢出。对照：账号管理页 `web/account.html` 用的是全局 `input{}` 选择器，所以那边正常。
- 修复：把 TOTP input 包进 `<div class="field">…</div>`，与密码框同一套样式。

**现象②：项目根积压 1100+ 个 `tmpXXXX` 目录（56MB）**

- 根因：测试用 `tempfile.mkdtemp()` 建临时库目录；**某些环境 `%TEMP%` 不可写**（如 WorkBuddy 沙箱），`tempfile.gettempdir()` 会回退到**当前工作目录**（项目根），于是一次测试跑完就撒一堆。实测：`gettempdir()` 在该沙箱下返回项目根，而 `TEMP` 环境变量明明指向系统临时目录——即候选目录全不可写时回退 cwd。
- 处置：**确认可删**（里面只有测试生成的空 `friend.db`/`outbox.log`/`archive.log`，未被 git 跟踪、`.gitignore` 有 `tmp*/`）→ 一次性清掉 1100 个。
- 根治：测试文件顶部收口——所有 `mkdtemp()` 落到固定目录 `.test-tmp/`（`.gitignore` + `.zcodeignore` 已加），**启动即清 + `atexit` 退出清双保险**。为什么用固定目录而非 mkdtemp 做根：Windows 上 sqlite 文件句柄在解释器退出时可能还没释放，`atexit` 的 `rmtree(ignore_errors=True)` 会因文件锁清不干净；固定目录 + 启动即清能自愈上次残留（只有一个 gitignore 的隐藏目录，不再污染项目根）。硬性约定新增第 11 条。

**现象③：AGENTS.md 对照表缺一批模块的文件说明**

- 补齐 `auth.py` / `auth_setup.py` / `reset_auth.py`、`main.py`/`core.py`、`scheduler.py`、`commands.py`、`persona_pool.py`、`diary.py`、`guard.py`、`game.py`、`llm.py`、运维脚本 / 配置文件 等行的「改了要同步哪里」；`web/` 行补上 `web/index.html`、`web/account.html`、`web/qr.js` 文件清单。

**踩坑记录**：`auth.LOGIN_PAGE` 是 `%` 格式化的字符串——CSS 里的裸 `%`（如 `width:100%`）必须写成 `%%`，否则 `/login` 渲染直接抛 `ValueError` 变 502（实测 #26 上线时踩过，本次登录页改动的注意事项已写进 AGENTS.md `auth.py` 行）。
