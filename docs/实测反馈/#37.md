# 实测反馈记录 #37（2026-10-10，语气主轨落地，v0.56）

**背景**：#36 的问题 6「语言割裂」是 S4 新主线的第一站（需求文档"下一步建议 #7"排第一），改动最小、直接治"上一秒怼下一秒分享"。

**根因**：语气是**多路各自为政、没有主轨**——`cost.prompt_hint()`（此刻的相处）、`mood.prompt_hint()`（此刻的心情）在 `context.py` 里各自独立注入；反谄媚五条里的「异议配额（第2条，要怼）」和「话题主权（第4条，要起话题分享）」是两个无条件指令。模型只好都做 → 一个 turn 里又怼又热情分享。

**落地（3 点）**：
1. **语气主轨**（新增 `tone.py`）：每轮定一个主导情绪状态（= mood，它已把 phase + 精力 + 时段合成一个词），打断成本降为从属的「相处姿势」（welcomed/tolerated/costly 的语态挂在主轨之下当"松紧度"），收敛成一条【此刻的我】块，替代原来散开的「此刻的相处」+「此刻的心情」两条。
2. **分享/异议排队**：反谄媚五条里补协调条款——「怼」（第2条）和「起话题分享」（第4条）**同一句只做一件**：忙/累/投入先怼、别起话题；放松/闲起话题、别硬怼。
3. **书名号 bug 修复**：#36 顺带发现的问题落地——`reading.py` 内置素材标题自带《》、`work.py` 又包一层 → 《《匆匆》》；改 `reading.py` 标题裸存、与 `library.py` 用户书库对齐（它本来就是裸的），`work.py` 只包一层。

**测试注意（踩坑）**：`tone.voice_hint` 的"睡着/关工作系统 → 空"用 `_db.set_state("SLEEPING")` 触发（`work.status` 只在 `planned` 缺失或 `SLEEPING` 时才判 sleep，靠"凌晨 4 点"不生效）；书名号断言要在 work_state 还没被改成 settled 之前做（忙/心流相位才返回"你在读《X》"，off 相位返回"事都忙完了"不含书名）。测试 53 项全过（新增 `test_tone_main_track`）。
