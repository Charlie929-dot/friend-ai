# 实测反馈记录 #30（2026-10-10，语义召回落地：本地 bge-small-zh-v1.5 混合召回）

**背景**：S4 首位「语义化召回」——用户早先指认"目前最大问题"是记忆召回纯字面，「几点睡」召不回「熬夜」。本次治本（v0.49）。

**方案**：本地向量（bge-small-zh-v1.5 + onnxruntime）+ 与字面 bigram 混合打分。落地要点：

**①DeepSeek 无 embedding API**：官方只有 chat/completions 端点，没有 embedding 端点。而云端 embedding（硅基流动等）会把记忆文本上传第三方、违背「数据永远只在本地」的卖点 → **必须本地**跑 bge-small-zh-v1.5（onnxruntime + tokenizers，不需要 torch/GPU/sentence-transformers）。实测向量区分度：`"他几点睡的"` → `"凌晨一两点才睡"` 余弦 0.877、无关句 <0.35。

**②模型约 100MB 不进 git**：GitHub/Gitee 单文件 100MB 限制，模型放 `models/`（已 gitignore）。**踩坑**：最初让 `sync-to-server.sh` 第 4 步「服务器自己从 hf-mirror 下载」，实测**服务器（腾讯云）连 hf-mirror 不通**（curl 15s 超时无响应，与之前"服务器连 GitHub 超时 134s"同源）→ 改成「**本机下载 → scp 直传**」：sync 脚本检测服务器无 `model.onnx` 时从本机 scp 上传（走 SSH，可靠）。本机下载命令已写进 AGENTS.md 服务器同步工作流。

**③测试 `main` 是显式调用列表**：`test_p1_features.py` 的 `__main__` 里逐条 `test_xxx()`，**新增 `test_*` 函数必须手动加进 `__main__`**，否则全量测试静默跳过它。这次踩到：加了 `test_semantic_recall` 只在单测里通过、全量根本没跑，差点漏测。已手动加进 `__main__`。
