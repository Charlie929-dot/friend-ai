# 实测反馈记录 #28（2026-10-10，素材库四连：UI 显示 0 / 避谈工作 / 假装读文献 / 素材不聊）

**背景**：用户反馈小葵素材库异常——网页 UI 显示"素材 0 条"，但 `/work` 显示"攒了 7 条没说过的素材"；问 TA 工作具体内容避而不谈；还假装说自己在读"文献"（其实工作=读书）；收集的素材也不主动聊。

**现象①：UI 素材数永远 0（真前端 bug）**

- 根因：`/api/state` 返回的 `materials` 是**顶层字段**（与 `work`/`cost`/`mood` 平级），但前端 `renderState` 写的是 `p.materials`，而 `p = s.work`（work 对象里根本没有 materials 字段）→ `undefined || 0 = 0`。`/work` 读的是同一份 `work_shareables` kv 所以显示 7。
- 修复：`web/index.html` 一行 `p.materials` → `s.materials`。

**现象②：问工作内容避而不谈**

- 根因：`work.prompt_hint()` 注入给 TA 的工作提示只有一句"你正在忙自己的事（今天第 N/M 件）"，**没告诉 TA 具体在读什么**（书名/篇目）。TA 根本不知道自己读的是书，答不上来就只能含糊回避。
- 修复（用户拍板"注入正在读的书/篇目"）：`prompt_hint` 在忙/心流相位追加 `_current_reading()`——优先用户书库（`library.progress()` + `books()` 拼书名+段数），退回内置书摘（`reading.current_article()` 的 source+title）。

**现象③：假装"读文献"其实在读书**

- 根因：全项目代码里**根本没有"文献"二字**，是 LLM 在信息不足时自己脑补的。注入工作内容（现象②修复）后，TA 知道自己读的是《海底两万里》/苏轼/王维，就不会再编"文献"。
- 顺带：生成素材的内部 prompt 让 TA"别出现'工作'这个词"，加剧了避谈——本次不改（那是素材生成时的措辞约束，与对话追问是两回事）。

**现象④：素材只攒不聊**

- 根因：`take_shareable()` 在代码里**没有任何生产调用点**——素材收集后只是攒着，"主动分享"（S4「主动分享内容生成」）一直没落地。
- 修复（用户拍板"现在做"）：`context._inject_random_topic()` random 场景一半概率翻一条素材（`work.take_shareable()`，翻过即消费）当话题；没素材才退回翻旧记忆。

**测试隔离教训**：测主动消息（`build_proactive_messages`）必须 `WORK_ENABLED=False`——否则 `build_system_prompt → work.prompt_hint → work.status()` 会触发排班+结算+后台生成素材（调 LLM），既慢又污染素材池断言。

**附带**：服务器同步工作流写入 `AGENTS.md`（sync-to-server.sh 用法 + 令牌加载 + 服务器备忘）。
