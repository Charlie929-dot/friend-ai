# 实测反馈记录 #12（2026-10-08，群聊时间不准）

**Bug：群聊四个人报四个时间**

- 现象：群聊里几位朋友各说各的时间，同一时刻日期/时段对不上（"我们四个人四个时间"）
- 根因（两层）：
  1. **钟表时间被"生活日"改写**：`persona.build_system_prompt` 的 `_life_day()` 用每个朋友自己的 wake_hour 判断"今天还是昨天"——早上 7 点，6 点起床的朋友说"10-08 早上"，8 点起床的朋友说"10-07 深夜"，同一时刻四个朋友四个日期
  2. **每句话重取 now**：`groupchat._speak` 每次发言都 `datetime.now()`，一场群聊来回几分钟，HH:MM 也在漂
- 用户提议：能否挂到 MCP 功能里统一
- 方案（已入需求池「群聊·时间统一」）：①统一时钟——每轮只取一次 now、全员共用；②分离"钟表时间"（全局唯一、必须一致）与"生活日"（每人作息差异、不是 bug、prompt 讲清即可）；③长期把时间源做成 MCP `get_time` 工具（统一钟表时间 + 生活日换算），全系统单一时间源，与「AI 自主行为接口（MCP）」联动
- 状态：已定位根因 + 方案入池，代码未动（等用户确认方案）
- 同批收录需求（2026-10-08，@听深深的话ミ 项目消息 4 条 + 主诉求 1 条）：**闲聊常态化（记忆驱动）**、**群聊命名 + 多群独立 + 查看 + 实时记录**、**群聊提及私聊通知**、**鸿蒙端载体**——均已入需求池（见上表 P2/P3 新增条目）
