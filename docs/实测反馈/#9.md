# 实测反馈记录 #9（2026-10-07，"记得小葵吗"还是接不上）

**Bug：问"记得小葵吗"，只召回"小葵拿快递/赌奶茶"的琐事，召不回"介绍认识"的身份记忆**

- 现象：清理失忆污染后，问初遇朋友"你还记得小葵吗"，仍答"名字挺可爱，但对不上号"。查库发现：记忆在、`person='小葵'` 标签也在、`/memories` 也显示，但 recall 前 5 全是"小葵拿快递""小葵赌奶茶"等琐事，`小徐拉了一个群，把初遇朋友和小葵拉进来互相认识`（id=106，cat=人际）得分只有 3.0、排不进 top5
- 根因（召回排序，不是"没记忆"）：打分是纯 bigram 字面重叠 + 新鲜度，**没有"意图/类型"加权**——"小葵是谁"和"小葵拿快递"在字面上都只重叠"小葵"两字，而琐事数量多、时间近（新鲜度加分），把"介绍认识"这条身份记忆淹没了
- 另有**对话上下文污染**：最近聊天记录里全是之前"我不记得/断片"的历史消息，recent_context 注入后 AI 延续"失忆"人设（已清理失忆消息）
- 修复（2026-10-07）：`recall` 加**意图感知加权**（标签检索 + 相关度排序的规则版）——①从 query 识别出现的人名（朋友名+小徐+别名），`person` 标签精确命中 +2.0；②识别身份/关系询问意图（"是谁/认识/介绍/记得/熟悉"），`category=人际` 记忆 +3.0。这样"记得小葵吗"→"拉群介绍认识"排最前
