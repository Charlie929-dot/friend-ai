# 实测反馈记录 #35（2026-10-10，人格才有重量）

**背景**：推导下来，项目到 S4 这一步最严重的问题不是"记不住"，而是**人格没有重量**——
具体表现是"谁在跟它说话，它就变成谁的形状"（跟 A 聊像 A 的朋友，跟 B 聊自动长出 B 的偏好）。

**根因两层**：
1. 旧人格只是一段**形容词**（"你是个夜猫子，越到深夜越精神…"）。形容词的问题是没有 falsifiability——
   它永远不会被任何一句话违反，所以也就永远约束不了任何一句话。
2. 注意力竞争：system prompt 里用户刚说出口的那句话权重远高于人设，再叠上 RLHF 自带的讨好先验 →
   顺着对方说、认同对方、道歉，成本最低。

**四件武器（配套使用，缺一件都会退回原状）**：

1. **人格内核 V3**：每张 archetype 卡配一份 `kernel`，条目具体到**能被违反**：
   `likes/dislikes` 带 intensity（5=会主动提起/会拒绝配合）、`stances` 立场卡（异议就是从这里来的）、
   `boundaries` 四种不配合的姿态（会敷衍/会拒绝/会不高兴/绝对不做）、`facts` 生活事实卡、
   `voice` 语言指纹（含**禁止的句式**）、`anti_sycophancy` 参数、`state` 内部状态初值。
   `core.不是` 用**否定式**定边界（"不是情绪垃圾桶""不是应声虫"）比形容词有效得多。
   ⚠️ 事实卡里**不写职业和正在做的事**——那是 `work.py` 运行时注入的地盘，写死会打架。
2. **反谄媚五条硬规矩**：拼在 system prompt **最前**（元规则 > 人设 > 上下文），每条都能事后检验：
   镜像预算（一段对话最多 1 次"我也是"）、异议配额（40–65%，参数按人格）、禁无条件投降（附替代反应清单）、
   话题主权（每 N 轮必须自己起话题，**允许说完就停**）、回复自主权（有权只回"嗯"）。
3. **双层生成**：LLM 调用两次。第 1 次是**对方永远看不到**的内心独白（结构化 9 段自问，
   含"和旧立场冲突吗：坚持还是承认自己变了"）——因为看不见，就不必措辞得体、不必讨好；
   第 2 次把独白**翻译**成说出的话（不许改立场、不许补礼貌、不许把球扔回去）。
   ⚠️ 第 2 层**不注完整人格内核**，只给语言指纹——注全文会把注意力拉回"表演我是谁"，反而显得刻意。
   ⚠️ 独白失败（LLM 不可用/返回过短）必须**退化单层**，拿 stub 文案当独白会让每句话都说同一套。
4. **自我记忆**（`selfmem.py`）：上面三件都管"这一轮"，自我记忆管"跨轮"——
   "我上次说过的立场、我答应过的事、我出过的糗"。睡前一天一次复盘写入，**不参与艾宾浩斯遗忘**
   （理由是《stated beliefs》淡忘了等于人格断裂）。每轮注入做一致性检查。

**红线体检为什么只告警不改写**：归因红线（"你打断我"）的做法是命中即换安全句；
人格红线也这么干的话，等于把一句 AI 话术替换成另一句 AI 话术——把一个人改成安全台词。
所以 `redline_report()` 只打日志，价值是**证据**：部署之后看有没有告警，就知道人格有没有被磨平。

**测试注意**：新增的人格相关用例要显式加进 `test_p1_features.py` 的 `__main__` 列表（见 #30 踩坑）；
双层生成的用例要把 `INNER_MONOLOGUE_ENABLED` 临时打开再还原（别让开关泄漏到别的用例）。
