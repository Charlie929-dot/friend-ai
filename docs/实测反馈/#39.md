# 实测反馈记录 #39（2026-10-11，修炼人格落地，v0.67）

**背景**：#38 对齐的「修炼人格（偏好养成）」阶段 B 落地。用户最终拍板：**纯规则固化、同一兴趣对象在流里出现 N 次自动转正、不调 LLM**。

**落地（新增 `interests.py`，5 处改动）**：
1. **`interests.py` 模块**：`record(topic)`（计数 + 达到阈值自动转正，返回是否刚转正）、`detect(text)`（信号词+主题词共现才命中，保守防误判）、`detect_and_record(text)`、`promoted()`、`random_promoted()`、`prompt_hint()`（渲染「最近喜欢上的」块，带"别编成正在做的事"约束）。存 kv `interests`，按朋友隔离。
2. **词表**（`corpus.py`）：`INTEREST_SIGNALS`（表达"感兴趣/想多了解"的语气）+ `INTEREST_TOPICS`（主题→关键词，key 对齐 reading 的 genre：科幻/散文/历史/杂文/热血/生活随笔 + 哲学/心理/科技/天文/物理/生物/文学/艺术等心智领域，**不放身体动作**，守住 #38 的编造生活红线）。
3. **三源落点**：阅读源 `work._settle` 结算读到 `article["genre"]` 直接 `record(genre)`（确定性最强、不经过词表）；聊天源 `core._inner_monologue` 独白 + `_generate_reply` 回复处 `detect_and_record`；刷手机占位。
4. **渲染 + 取材**：`persona.kernel_prompt` compact/full 层追加「最近喜欢上的」块（**追加不是改内核**）；`context._inject_random_topic` random 场景从转正兴趣取材当话题弹药。
5. **配置**：`INTEREST_PROMOTE_ENABLED`（默认 on）+ `INTEREST_PROMOTE_THRESHOLD`（默认 3）。

**设计取舍**：
- **内核钉死不漂移**：修炼只追加到兴趣偏好层，archetype 的 likes/stances/kernel 一个字不改——守住"朋友是稳定的锚"（用户 2026-10-08 宗旨）。
- **保守检测**：聊天源要求"信号词 + 主题词共现"，否则"今天读了三章历史"（只有主题词）会被误判成兴趣——读书≠喜欢上历史；"我有点上头"（只有信号词）不命中。
- **转正不调 LLM**：纯规则计数，阈值 3，跨天累计（存 kv 不清零）。

**测试**：59 项全过（新增 `test_interest_cultivation`：detect 保守性 + 阈值转正 + 内核追加注入 + 防编造约束 + 开关关闭失效）。
