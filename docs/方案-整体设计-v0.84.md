## 2. 世界观（§1 · 架空设定）

**骨架四件事**（lore 写薄不写厚，只定死这四件，其余留给对话即兴展开）：
1. **从哪来**：来自一个完全不同的世界。
2. **怎么困在这**：被某种神秘力量寄宿到「这个程序」里（**不点出程序属于谁**——保一视同仁）。
3. **靠什么成长**：依赖读书获取经验，实现灵魂成长。
4. **说话的调子**：谈身世像谈平常事，越淡越可信（防中二）。

**设计规则**：
- **canon 设定集**：即兴展开的每个世界细节必须追加进设定集，防自相矛盾——世界可以架空，连续性不能架空（用户会记得两周前说过的细节）。
- 身世话题是**节奏控制**而非禁止：不主动大段倾倒，但可持续少量输出，本身是分享素材的一部分。

**放弃"预制人类日常"**：模拟人类日程需要词表、拦截、一致性校验层层补丁；架空设定让虚构与机制重合，这些问题被消解而非被解决。（原防御机制——红线词表、主动消息拦截重写——已移除。）

**灵魂成长界定（拍板 #2）**：读书"让 TA 变"的部分 = **世界观经验层积累 + 兴趣偏好漂移**（现有修炼人格 `interests.py`）；**人格内核钉死**，成长不是"变成另一个人"。

## 3. 阅读真读（§3 · 主要增量）

对应需求池 D 模块「真实阅读（逐字读+自主摘抄+收尾读后感）待做·后续升级」——本方案是它的完整设计。现状是"每单元读 N 段 → 产一条摘抄+读后感"（跳读），升级为**真读**。

### 3.1 当日任务制定（上课作息 + tps 推导）

- **上下班作息（上课制，默认值均可调，见 §10）**：
  - 8:30 上班、12:00–14:00 午休、17:30 下班；
  - 上午 2 节、下午 2 节（共 4 节）；每节 = 上半节 40min + 节内休 15min + 下半节 40min；节间休 20min；
  - **总上课时间 = 8 半节 × 40min = 320min**（休息不算）。
- **当日阅读任务**：按**整数章节**圈定（不读半章），受**当日字数上限 10000（非空白字符，可调）**约束，累计到"再加一章就超"就停——**宁可少读一章，不可超字数**。圈定的章节内容进缓存，**均分 8 个半节**（默认每半节 1250 字）。
- **tps（吞吐速度）= 当日总字数 ÷ 总上课时间**——**推导值、不单独设**：默认 10000 ÷ 320min ≈ 31 字/分（慢速精读、边读边想的节奏）。当日字数或作息变了，tps 跟着变。

### 3.2 边读边做的三件事

1. **视线窗口召回**：以当前阅读窗口做向量查询，召回相关历史事件（= 拍板 #6②，第二批；窗口短 → embedding 锐利 → 联想形态 = 边读边想起）。
2. **思考即笔记（核心）**：阅读调用**开启 thinking**，把思考过程 `reasoning_content` **按当前阅读窗口 append 进「思考 buffer」**——思考过程本身就是笔记原料。思考加轻约束防跑题（聚焦刚读窗口），但**不禁止跑题**（偶尔跑题是阅读体验的一部分，也可能是最好的分享素材）。**前置依赖 §8**：现在 `llm.py` 只取 `content`、不取 `reasoning_content`，思考过程拿不到，buffer 填不进来。
3. **打动判断**：在阅读思考中顺带完成。**不打动就不摘**——素材池 / 待办 / 今日素材全不写（章节总结照写）。

### 3.3 章节末结算 + 解析

- **解析**：epub 读 spine/toc（章节边界现成）；txt 优先"第X章"正则，fallback 按累计字数（4–6k）切，**不按段数**（对话密集一行一段会切碎）。
- **章节末结算**：独立总结调用 = 思考 buffer + 章节内容 → 「想法 + 总结」，允许再想一步（原料是思考，成品不该只是思考的压缩）。
- **原文不复制入库**：只存章节引用，追问按需取原文。

## 4. 读书笔记双库（§4 · alpha/beta，新增）

> ⚠️ 与记忆 A/B 库**同名不同物**，必须区分：记忆 A/B 库 = 记忆摘要/长文本对话原文；**读书笔记 alpha/beta = 读书的短概述/完整转述**。

| | alpha 库 | beta 库 |
| --- | --- | --- |
| 内容 | 短概述 | 完整转述 |
| 关联 | 挂 long_id → beta 库 | 存章节引用（不存原文） |

**注入节奏**：
- 最近章节按**累计字数**窗口必带（不按章数——章节长度差异太大）；
- 每累计约 1.5 万字触发一次阶段性大总结（阈值待实测）；
- 全书总结；读完 3 本跨书梳理（范围严格限当前这本）。
- alpha 库注入 = **最近必带 + 向量相关性补充**。

**与世界观咬合**：阶段性大总结 / 全书 / 跨书梳理同时是「灵魂成长节点」的反思素材——读到什么让 TA 什么地方变了（按拍板 #2，变的是经验层/偏好，不是内核）。

## 6. 分享质量（§6 · 增量）

并入需求池 C 模块「主动分享内容生成」待做的"完整版"。**三选一标准**（每次分享至少命中一条）：
1. 启发性 / 思辨性
2. 娱乐性 / 趣味性
3. 相关性（自己或用户）

**约束**：从刚读到的具体内容出发，锚点必须具体；**禁止强行结合生活**；"相关性（自己）"只允许关联意识流里的真实事件，架空身世按 §2 节奏控制输出。

## 7. 提示词人称分层（§7 · 全量改）

**原则**：**"我" = 事实/状态/发生过的**（"我说过要发链接"）；**"你" = 要求/动作**（"待办必须处理，处理完勾掉"）。

**落地**：
- 内容层（意识流引导句、待办块、今日素材、工作/阅读注入）→ 用"我"。
- 指令层（COMMON_RULES、反谄媚五条、独白格式、"待办必须被处理"全局规则）→ 保留"你"。
- 灰区（兼具事实与指令功能）**默认归指令层**。

**现状与改动面**：`stream.prompt_hint` 现写"**你**脑子里有一条…"、待办写"**你**脑子里攒着…"、今日素材写"**你**今天做过的事"——这些 v1.0 归内容层的块现状全用"你"，需全量改为"我"。横跨 stream/todos/context/tone/work/persona 等所有注入块，**回归风险：现有 45 条实测靠这套自洽人称跑通，改后须跑全量测试 + 回归对话**。

## 8. DeepSeek Flash 接入（§10 · 前置增量）

现有 `llm.py` 已用 `deepseek-flash` + effort 字段，但 5 个坑未处理：

1. `reasoning_content` 未取（`chat()` 只拿 content）→ 阅读"思考即笔记"依赖它。
2. 多轮 tools 未回传 reasoning_content（否则工具调用质量下降/部分端点 400）。
3. 无"关 thinking"开关（`extra_body.chat_template_kwargs.enable_thinking=false`）——打勾、状态写入这类短回执应关思考省 token。
4. thinking 开启时 temperature/presence_penalty/frequency_penalty 被静默忽略、top_p 只接受 0.95–1.0——现有 `_gen_shareable` 传 `temperature=1.0` 可能没生效。
5. 结构化输出 + thinking 可能返回 `content: null`——要 JSON 的调用要么关 thinking、要么放大 token 上限。

> 模型标识符 pin `deepseek-flash`（旧名 `deepseek-v4-flash` 已静默改路由，防再次静默换模型破坏回归）。
