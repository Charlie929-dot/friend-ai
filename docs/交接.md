# 交接（滚动）

> **定位**：跨会话/跨机器的「当前进行中」唯一入口——治"工作散在各个 AI 会话里，换会话就断线"。
> **用法**（配套 AGENTS.md 顶部「会话第一动作」+ 必做 #6）：
> - **开场**：拉最新 → 读本块 → 核对仓库实况（`git log -5`、需求池状态）再动手。**本块是历史方向、不是事实真相；与仓库实况矛盾时以仓库为准**。
> - **更新时机 = 工作单元**：开工做多轮的事，先写一行「目标+下一步」（保险）；每走完一次五步必做就刷新本块。**长任务每个子里程碑（做完一个文件/一组测试转绿）顺手刷新「已验证进度」行**——会话挂了之后，未提交改动还在磁盘上，中途决策和"哪些已跑绿"只活在这行里。**不每轮写、不等会话结束补**——会话经常是被关掉的、不是结束的。
> - **只有一个 next_action**：排队的事进需求池，这里不许长成第二个需求池。历史去 `docs/版本更新记录.md` 和 `.workbuddy/memory/` 工作日志，这里不重复记。
